# Başlanğıc

Rust səyahətinizə başlayaq! Öyrəniləcək çox şey var, amma hər səyahət haradansa
başlayır. Bu fəsildə bunları müzakirə edəcəyik:

- Rust-ı Linux, macOS və Windows-da quraşdırmaq
- Ekrana `Hello, world!` yazan proqram yazmaq
- Rust-ın paket meneceri və build sistemi olan `cargo`-dan
  istifadə etmək

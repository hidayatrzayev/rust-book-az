# Rust Proqramlaşdırma Dili

_Müəlliflər: Steve Klabnik, Carol Nichols və Chris Krycho, Rust icmasının
töhfələri ilə_

Mətnin bu versiyası sizin Rust 1.99.1 (2026-10-15 tarixində çıxıb) və ya daha
yeni versiyadan istifadə etdiyinizi güman edir. Bütün layihələrin *Cargo.toml*
faylında `edition = "2024"` olmalıdır ki, layihələr Rust 2024 buraxılışının
idiomlarından istifadə etsin. Rust-ı necə quraşdırmaq və ya yeniləmək barədə
təlimatlar üçün [1-ci fəslin “Quraşdırma” bölməsinə][install]<!-- ignore -->,
buraxılışlar haqqında məlumat üçün isə [Əlavə E-yə][appendix-e]<!-- ignore -->
baxın.

HTML formatı onlayn olaraq
[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
ünvanında, oflayn olaraq isə `rustup` ilə quraşdırılmış Rust-da mövcuddur;
açmaq üçün `rustup doc
--book` işə salın.

İcmanın hazırladığı bir neçə [tərcümə][translations] də mövcuddur.

Bu mətn [No Starch Press-dən kağız və elektron kitab formatında][nsprust] əldə
edilə bilər.
